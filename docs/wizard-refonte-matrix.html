B. Affichage conditionnel des modules

Pour chaque module, sélectionne les conditions qui le rendent visible. Si aucune condition n’est cochée → module toujours visible. Plusieurs conditions cochées = OU logique.

« Niveau 0 forcé » = le module reste dans le profil mais figé à 0 (cohérent avec moteur). « Masqué » = pas affiché du tout.

C. Niveau initial recommandé par module

Pour le mode Express et comme défaut intelligent dans le mode Expert. Choix : 0 (off), 1 (basique), 2 (moyen), max. Aujourd’hui tout est au max → c’est ce que tu critiques.
